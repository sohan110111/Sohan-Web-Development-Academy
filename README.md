## 📘 About the Academy

**Sohan Web Development Academy** is a specialized learning program created and led by **Md. Shafiul Islam Sohan**, focused on teaching **kids & teens (10–14 years old)** real-world web development through a structured, age-based curriculum.

This repository contains the **official website code**, student roadmap, and educational resources.

---

## 🎯 Mission

> *To help young students become confident, creative and future-ready web developers through real projects, modern tools, and step-by-step guidance.*

---

## 📚 Curriculum Overview (Age 10–14)

### 🔵 Age 10–11 — **Foundation**

* Scratch, Code.org
* Logic building games
* Basic computer skills
* Intro to the internet & safety

---

### 🟢 Age 11–12 — **Web Development Start**

* HTML & CSS fundamentals
* Page structure, layout
* First personal website

---

### 🟡 Age 12–13 — **JavaScript Programming**

* Variables, loops, functions
* DOM manipulation
* Events & interactive features
* Git & GitHub basics
* Mini-projects (Calculator, Quiz, Clock)

---

### 🔴 Age 13–14 — **Modern Web Developer Track**

* React basics (components, state, props)
* Next.js introduction
* APIs & JSON
* Node.js basics
* MongoDB beginner CRUD
* Portfolio building & deployment
